## 3.1 What Is an Instruction?

**Definition:** An instruction is a single command that tells a computer what operation to perform.

**Examples:**
- Read two numbers.
- Add two numbers.
- Display the result.

A computer program consists of instructions arranged in a logical order.

## 3.2 What Is an Algorithm?

**Definition:** An algorithm is a finite sequence of clear, step-by-step instructions used to solve a particular problem.

### Characteristics of an Algorithm

1. **Input:** It may accept zero or more inputs.
2. **Output:** It produces at least one result.
3. **Definiteness:** Every step must be clear and unambiguous.
4. **Finiteness:** It must finish after a finite number of steps.
5. **Effectiveness:** Every step must be simple and executable.

### Advantages of an Algorithm

- Makes problem-solving easier.
- Provides a clear sequence of steps.
- Helps identify logical errors.
- Makes program development easier.

## 3.3 What Is a Flowchart?

**Definition:** A flowchart is a graphical representation of an algorithm using standard symbols connected by arrows.

### Common Flowchart Symbols

| Shape | Name | Purpose |
|---|---|---|
| Oval | Terminal | Represents Start or End. |
| Parallelogram | Input/Output | Reads input or displays output. |
| Rectangle | Process | Performs calculations or operations. |
| Diamond | Decision | Checks a condition and selects a path. |
| Arrow | Flow Line | Shows the direction of execution. |

### Advantages of Flowcharts

- Makes the logic easy to understand.
- Shows the sequence of operations.
- Helps detect mistakes in program logic.
- Makes program planning easier.

## 3.4 Algorithm to Find the Sum of Two Numbers

**Problem:** Find the sum of two numbers.

### Algorithm

1. Start.
2. Declare variables `a`, `b`, and `sum`.
3. Read `a` and `b`.
4. Calculate `sum = a + b`.
5. Display `sum`.
6. Stop.

### Example

Input: `a = 10`, `b = 20`

Calculation:

`sum = 10 + 20 = 30`

Output: `Sum = 30`

### Flowchart Sequence

Start → Input `a, b` → Calculate `sum = a + b` → Output `sum` → End

## 3.6 Algorithm to Find the Average of Three Numbers

### Formula

Average = (Sum of all numbers) / (Number of numbers)

### Algorithm

1. Start.
2. Declare variables `a`, `b`, `c`, and `average`.
3. Read `a`, `b`, and `c`.
4. Calculate `average = (a + b + c) / 3`.
5. Display `average`.
6. Stop.

### Example

Input: `a = 10`, `b = 20`, `c = 30`

Calculation:

`average = (10 + 20 + 30) / 3 = 20`

Output: `Average = 20`

### Flowchart Sequence

Start → Input `a, b, c` → Calculate Average → Output Average → End

## 3.7 Difference Between Algorithm and Flowchart

| Algorithm | Flowchart |
|---|---|
| Represents a solution in written steps. | Represents a solution graphically. |
| Uses simple statements. | Uses standard symbols and arrows. |
| Easy to write and modify. | Often easier to understand visually. |
| Does not require drawing symbols. | Requires drawing symbols. |
