## 1.1 What Is Software?

**Definition:** Software is a collection of programs and instructions that tells a computer how to perform specific tasks.

Software helps users interact with computer hardware and process data to produce useful information.

**Examples:** Windows, Linux, MS Word, Google Chrome, and VLC Media Player.

## 1.2 Types of Software

Software is mainly classified into two types:

1. System Software
2. Application Software

### A. System Software

**Definition:** System software controls and manages computer hardware and provides a platform for application software to run.

**Functions:**
- Manages computer hardware and system resources.
- Controls the operation of the computer.
- Provides a platform for application software.
- Helps the computer run efficiently.

**Examples:**
- Operating systems: Windows, Linux.
- Language translators: Compiler, Interpreter, Assembler.

### B. Application Software

**Definition:** Application software is designed to perform specific tasks for users.

**Functions:**
- Helps users perform daily tasks.
- Supports educational and business activities.
- Helps create documents, spreadsheets, and presentations.

**Examples:**
- MS Word — document preparation.
- MS Excel — calculations and spreadsheets.
- MS PowerPoint — presentations.
- Google Chrome — web browsing.

## 1.3 Difference Between System Software and Application Software

| System Software | Application Software |
|---|---|
| Manages hardware and system resources. | Performs specific tasks for users. |
| Provides a platform for applications. | Runs with the support of system software. |
| Often works in the background. | Usually interacts directly with users. |
| Examples: Windows, Linux. | Examples: MS Word, MS Excel. |
