## 2.1 What Is a Computer Language?

**Definition:** A computer language is a language used to write instructions that enable a computer to perform specific tasks.

Programmers use computer languages to communicate instructions to a computer.

## 2.2 Types of Computer Languages

The three commonly studied levels of programming languages are:

1. Machine-Level Language
2. Assembly-Level Language
3. High-Level Language

### A. Machine-Level Language

**Definition:** Machine language is the lowest-level programming language, consisting of binary digits (0 and 1), which are directly understood by the processor.

**Features:**
- Uses only binary digits (0 and 1).
- Directly understood by the processor.
- Difficult for humans to read and write.
- Machine-dependent.

**Example:** `10110000 01100001`

### B. Assembly-Level Language

**Definition:** Assembly language uses symbolic instructions called mnemonics to represent machine operations.

**Features:**
- Uses short instruction codes.
- Easier to understand than machine language.
- Requires an assembler to translate it into machine code.
- Usually machine-dependent.

**Examples:** `MOV`, `ADD`, `SUB`.

### C. High-Level Language

**Definition:** A high-level language uses human-readable instructions and syntax to write computer programs.

**Features:**
- Easier to learn and understand.
- Uses readable keywords and expressions.
- Generally requires a compiler or interpreter.
- Usually more portable than low-level languages.

**Examples:** C, C++, Java, and Python.

## 2.3 Language Translators

Language translators convert programs into a form that a computer can execute.

### Compiler
A compiler translates a high-level program into machine code or another lower-level form before execution.

**Example:** A C compiler.

### Interpreter
An interpreter executes a program by processing its instructions, often one at a time.

### Assembler
An assembler translates assembly-language instructions into machine code.

## 2.4 Difference Between the Three Types of Languages

| Machine Language | Assembly Language | High-Level Language |
|---|---|---|
| Uses binary digits. | Uses mnemonics. | Uses readable statements. |
| Directly understood by the processor. | Requires an assembler. | Usually requires a compiler or interpreter. |
| Difficult to write and understand. | Easier than machine language. | Generally easiest for humans to understand. |
| Machine-dependent. | Usually machine-dependent. | Often more portable. |
