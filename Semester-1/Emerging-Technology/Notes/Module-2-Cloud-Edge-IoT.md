# Module 2 — Digital Foundations: Cloud, Edge, IoT & Connectivity

## 1. Cloud Computing
Cloud computing provides computing resources—such as servers, storage, databases, and software—over a network, usually the internet.

**Examples:** Google Drive for online storage; AWS for cloud infrastructure.

### Main Cloud Service Models
- **IaaS (Infrastructure as a Service):** Rent computing infrastructure such as virtual machines and storage.
- **PaaS (Platform as a Service):** Use a managed platform to build and deploy applications.
- **SaaS (Software as a Service):** Use software through the internet, often in a browser.

### Three Main Cloud Deployment Models
1. **Public Cloud:** Services run on cloud infrastructure offered to multiple customers.
2. **Private Cloud:** Cloud infrastructure is dedicated to one organization.
3. **Hybrid Cloud:** Combines private infrastructure with public cloud services.

## 2. Edge Computing
Edge computing processes data near the device or place where it is produced instead of sending everything to a distant cloud server.

**Example:** A security camera detects movement locally, reducing delay.

## 3. Internet of Things (IoT)
IoT is a network of physical devices containing sensors, software, and connectivity so they can collect and exchange data.

- **Sensor:** Collects information, such as temperature.
- **Actuator:** Performs an action, such as switching a motor on.
- **Device identity:** Helps distinguish one connected device from another.

**Example:** A smart irrigation system measures soil moisture and activates watering when needed.

## 4. Basic Computing Stack
A simplified system may include devices/hardware, operating system, applications, networks, APIs, and local or cloud data storage.

## Short exam answer: Cloud Computing
Cloud computing is the delivery of computing services such as servers, storage, databases, and software over the internet. It helps users access resources on demand without owning all the underlying infrastructure.

## Compare: Cloud vs Edge
| Cloud Computing | Edge Computing |
|---|---|
| Processing often occurs in remote data centres. | Processing occurs near the data source. |
| Useful for large-scale storage and analysis. | Useful when low delay is important. |
| Usually depends on network connectivity. | Some processing can continue locally. |
