# Module 3 — Data Literacy & Analytics Thinking

## 1. Types of Data
- **Text:** Documents, messages, reviews.
- **Image:** Photos, scans, medical images.
- **Audio:** Speech and recordings.
- **Logs:** Records of events produced by software or devices.

## 2. Structured vs Unstructured Data
- **Structured data:** Organized in a predefined format, such as rows and columns in a spreadsheet.
- **Unstructured data:** Does not follow a simple fixed table structure, such as images, audio, and free-form documents.

## 3. Data Lifecycle
A simple data lifecycle is:

**Collection → Cleaning → Labelling → Storage → Access/Use → Review**

- **Collection:** Gather data from suitable sources.
- **Cleaning:** Fix errors, duplicates, and inconsistent values.
- **Labelling:** Add meaningful tags or categories to examples.
- **Storage:** Save data in an appropriate, protected location.
- **Access control:** Decide who can view or change the data.
- **Versioning:** Track changes to datasets over time.

## 4. What is Data Labelling?
Data labelling is the process of assigning meaningful tags or categories to data so it can be searched, analysed, or used to train machine-learning models.

**Examples:**
- Marking an image as “cat” or “dog”.
- Marking an email as “spam” or “not spam”.
- Adding “positive”, “negative”, or “neutral” labels to reviews.

Incorrect or biased labels can reduce the quality and fairness of a model.

## 5. What is Data Storage?
Data storage is the process of saving digital information so it can be accessed and used later.

**Examples:** A computer drive, a database, an external drive, or cloud storage.

Important considerations include security, access permissions, backups, cost, reliability, and privacy.

## 6. What is Data Visualization?
Data visualization is the presentation of data in a visual form—such as charts, graphs, or maps—to make patterns and comparisons easier to understand.

### Common chart types
- **Bar chart:** Compare categories.
- **Line chart:** Show change over time.
- **Pie chart:** Show parts of a whole when there are only a few categories.

### Choose, Plot, Interpret, Communicate
1. **Choose:** Select a suitable chart for the question and data.
2. **Plot:** Create the chart with clear labels and units.
3. **Interpret:** Explain the pattern or comparison shown.
4. **Communicate:** Present the main finding clearly, without misleading the audience.

## 7. Data Quality Issues
- **Missingness:** Some values are absent.
- **Noise:** Data contains random errors or irrelevant variation.
- **Bias:** Data does not represent all relevant groups fairly.
- **Duplicates:** The same record appears more than once.

## 8. Analytics Ladder
- **Descriptive:** What happened?
- **Diagnostic:** Why did it happen?
- **Predictive:** What may happen next?
- **Prescriptive:** What action should be considered?
